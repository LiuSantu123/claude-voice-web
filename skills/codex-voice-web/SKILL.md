# codex-voice-web — Codex 语音对话

在浏览器里与 Codex 连续语音对话（说一句回一句，自动断句、自动朗读回复并继续聆听）。

## 目录

- 项目根目录：`<skill 所在仓库>/`（本 skill 通常与该仓库一起被安装或克隆）
- 服务端：`server.py`
- 前端：`frontend/`

## 启动步骤

1. 确认服务是否已在运行：`curl -sS -m 3 http://127.0.0.1:8765/api/health`
2. 若未运行，找到项目目录并：
   ```bash
   cd <codex-voice-web 项目目录>
   [ -x .venv/bin/python ] || ./setup.sh        # 首次需安装依赖
   nohup .venv/bin/python server.py --port 8765 > /tmp/codex-voice-web.log 2>&1 &
   ```
3. 等待 2~3 秒后再次 `curl -sS http://127.0.0.1:8765/api/health` 确认。
4. 告诉用户在浏览器打开：**http://localhost:8765**
5. 引导用户：点“开始对话”→ 授权麦克风 → 选择设备/音量 → 选择“自动”或“按键”模式 → 说话。

## 使用说明（给用户）

- **页面布局**：左侧是设置（设备/音量/模式/音色），右侧是对话记录。
- **自动模式**：直接说话，停顿约 0.7s 自动发送；回复播完后自动继续听。
- **按键模式**：左侧可选两种录音方式：
  - **双键切换（默认）**：按“开始录音键”（默认 F8）开始录音，按“结束并发送键”（默认 F9）停止并发送；键位可点击自定义
  - **按住说话**：按住“说话键”（默认空格）录音，松开自动发送
- **思考动画**：Codex 处理期间，右侧对话区会显示转圈 + “Codex 思考中…”提示。
- **发送前预览**：默认开启，识别完后先在右侧预览框显示文字，可修改后“确认发送”，或“重新录音/取消”。
- **导出 MD**：右侧工具栏“📥 导出MD”把对话记录导出为 Markdown。
- **终端恢复**：每次对话会拿到 Codex 的 thread_id（工具栏显示“会话 xxxxxxxx”）；点“📋 复制ID”或“💻 终端恢复”会复制 `codex exec resume <thread_id>`，在终端执行即可用同一会话继续对话。
- **思考与操作展示**：默认开启“显示 Codex 思考与操作”，对话过程中右侧实时显示 Codex 实际执行的命令、退出码与输出（可折叠），以及 token 用量。
- **设备**：左侧可切换麦克风/扬声器；授权麦克风后设备列表会自动刷新（也可点🔄）。
- **语音**：左侧可选音色（晓晓/云希/粤语/英文等）、语速、语调，并可“试听”。
- **记忆**：同一页面会话内 Codex 记得之前对话。

## 常见排障

- 服务没起来：看 `/tmp/codex-voice-web.log`
- 首次启动慢：Whisper 模型在下载（hf-mirror），稍等
- 麦克风没声：浏览器地址栏/设置里允许麦克风权限；页面内选择正确设备
- 听不到回复：确认扬声器设备选择正确、输出音量>0；Windows 下若默认输出是虚拟声卡，请在系统声音设置改回实体设备
- 转写不准：靠近麦克风、调高“输入音量”，或把 Whisper 模型换成 `--model small`

## 停止服务

```bash
pkill -f "server.py --port 8765"
```
